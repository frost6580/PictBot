# Pictsense Python Bot Library

Pictsense（ピクトセンス）の操作を自動化・ボット化するためのPythonライブラリです。
イベント駆動型の設計により、チャットへの自動応答、描画の自動化、ゲーム進行管理などを直感的に記述できます。
